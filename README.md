# 我的第一个 Git 仓库

这是我学习 Git 和 GitHub 的练习项目。

## 这个项目是干什么的

一个最简单的小工具：跟世界打个招呼。

## 怎么运行

```bat
python hello.py
python hello.py 小明
```

## 我用到的命令

```bat
git status          :: 看当前状态
git add .           :: 把改动放进"待提交区"
git commit -m "..."  :: 生成一次提交
git log --oneline   :: 看提交历史
git push            :: 推送到 GitHub
```
